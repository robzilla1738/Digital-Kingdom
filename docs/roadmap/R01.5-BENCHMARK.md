# R01.5 search benchmark

Machine: Neoverse-V2 (arm64), 2 cores, 8 GB RAM, Node v22.23.3, Linux sandbox. File-backed SQLite (WAL, synchronous=FULL). Synthetic events inserted directly (5 assets, 4 sources, 4 actions, 30 days). Best of 3 runs per search; each search returns one page of 50 plus counts and current source coverage, exactly as `GET /events/search` does.

Reproduce: `pnpm tsx scripts/bench-search.ts 10000 100000 1000000`. Raw results: `R01.5-bench-before.json` (branch state before R01.5) and `R01.5-bench-after.json`.

## What changed and why

- **Coverage per request was the dominant cost** (a full rule evaluation over a 50,000-event window on every search, context and health call). It is now derived from source declarations plus one index seek per source: about 1 s to under 1 ms at 1M events.
- **Plans before**: `SEARCH events USING INDEX events_project_time` plus `USE TEMP B-TREE FOR LAST TERM OF ORDER BY` for every query, with JSON filters evaluated row by row. **After**: covering `events_time_id (project_id, occurred_at, id)` (no sort) and expression indexes such as `events_actor` for identity filters.
- **Counts are capped** at 100,000 (`matching_capped`), so an unfiltered month no longer costs a full count. Per-source interval counts use `events_source_time` and stop at 10,000.
- **Health lookup**: an `IN (...)` list made SQLite sort a whole source's events (28 ms per source at 300k); it is now two equality seeks.

## Costs and limits (honest)

- Eleven indexes make bulk insert about 4 to 5 times slower and the file about 2 times larger. Real ingestion throughput (journal, redaction, rules) is measured separately in R10.2; this benchmark bypasses it.
- Requests are synchronous on one event loop. They are bounded (count cap, 1 MB page budget, keyset pages, per-principal 30 searches per 10 s), not cancellable mid-query. The worst measured request at 1M events is about 175 ms here.
- One machine, synthetic uniform data. Skewed data (one hot actor, one huge source) and concurrent ingestion under load are not measured.
