# Enabled-capability audit

This audit describes actual controls and existing contracts, not enabled enforcement or a release approval. Tests and final execution receipts are listed separately in `acceptance-results.json`.

| Surface | Supported behavior | Boundary shown to the operator |
| --- | --- | --- |
| Kingdom | Select real graph assets/relationships and exact finding/event associations; independent Castle/Graph cameras; explicit Focus; bounded grouped membership; roofs, layers, quality, fit, zoom, camera return; relationship chooser. | Selection does not imply camera movement. Declared topology is not observed traffic. Hypothetical paths are off by default. Group summaries are presentation-only and do not aggregate evidence into invented incidents. Overflow keeps a complete membership list. |
| Investigate: Findings | Canonical finding queue, genuine primary-area expansion with a filtered previous/next queue, preserved return context, existing role-gated dispositions/notes/proposals, and exact evidence cards with retained partial pages and revision drift checks. Source/action/outcome, both timestamps, redaction and bounded inert raw text remain inside the pinned comparison. | A finding source filter is unavailable because the canonical finding contract has no authoritative source IDs. Proposals do not execute containment. Approval is not claimed. Optimistic concurrency and arbitrary historical evidence revisions are not available. |
| Investigate: Events | Deliberate server search with existing filters, opaque cursors and exact archived event lookup; independent display pages cap rendered rows at 100 without discarding loaded server pages. Inspect unlinked records and jump to their recorded assets. | Snapshot bounds are not search completeness. Failed next pages keep loaded records and disclose incompleteness. Query drafts are not sent on each keystroke. Unlinked success does not prove safety or downstream causality. |
| Coverage | Current sources, freshness/completeness, source-reported state and affected asset lists; source and asset counts remain distinct. Unknown assessments do not assert a confirmed outage. | Unobserved, partial, unknown, stale and unavailable are not healthy. Current source administration is not historical coverage. A source can affect several assets without becoming several unavailable sources. |
| Integrations | Accurate SDK, OTLP JSON, Falco and MCP guidance with scoped declared-source configuration and distinct reporting/gap/disabled/unassessed counts; manifest/Compose preview and authorized server import; privacy-safe reference configuration. A fresh server checklist derives progress from inventory, source records and actual event/source timestamps. | No fabricated connected state, no automatic source/key creation, no secret persistence, no unsupported protocol promise. Invalid imports preserve drafts and show authoritative field paths. Browser preview does not override server validation. |
| Shared inspector | Nonmodal selected-record detail and shared expanded finding mode; explicit close; links to related canonical records; authorized summary/complete evidence export and copy/reference actions. | Role and backend capabilities gate controls. Explicit export is sensitive-data aware; stale session/project/role work is aborted or discarded. Partial evidence cannot silently become a complete case. |
| Timeline | Latest/replay separation; known-time and event-time modes; exact records in bounded expanded lanes; custom interval; explicit Return to latest. | Playback stops at its historical end. Actual graph revision and unavailable historical topology, current coverage and current annotations remain visible. No fabricated historical graph/coverage. |
| Renderer recovery | Real WebGL context loss falls back to Graph with selected IDs, interval and loaded evidence retained; explicit Retry 3D. | Local geometry/model faults and compile/link failures in explicitly owned body, roof and directional-depth programs use a labeled neutral block with the same logical asset and footprint. Every live owner of an affected shared module-family program is notified; unrelated families remain usable. Unowned scene shader failures use Graph rather than guessing an asset. Arbitrary asynchronous driver faults are not claimed as individually attributable. Graph and lists are not degraded evidence modes. Retrying graphics does not repair source coverage or modify backend findings. |
| Authorization and delivery | Existing server authorizes every endpoint; UI clears sensitive state and cancels prior-scope requests; ordinary branch CI only. | No new enforcement, persistent access, runtime model calls, paid evaluations or human approval. Main integration and its automatic Pages result require the user’s separate authorization, which was subsequently granted for the necessary task/dependency chain after green checks. |

Display preferences include a page-session option to reduce automatic status announcements while retaining direct selection, filter, action and error feedback. This is implemented behavior, not a claim of completed manual screen-reader acceptance.

## Supported but externally gated

Human architectural/visual judgment, manual assistive-technology tasks, physical reference-device performance, and representative-human formative usability remain explicit release gates. Automated source inspection, software WebGL and axe do not clear them.
