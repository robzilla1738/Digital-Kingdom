# LP18 — Add evidence-linked interiors (receipt)

Milestone M4, branch `phase/li-m4`. Status: **implemented_locally_verified** (contract/API/MCP, inspector view, castle interior markers; server, MCP and browser tests).

## Substage 1 — contract, API and MCP
- `packages/scene-compiler/src/interior.ts` (`dk.asset_interior.v1`, exported from `@dk/scene-compiler`): `buildInterior()`
  turns ONE asset's authoritative records into typed interior objects — declared routes (with template-matched
  recorded requests), grants and credential references from the latest authorization snapshot (key id + status only),
  `runs_as`/`may_assume` grants, `reads_from`/`writes_to` data relationships, recorded data accesses, covering sources
  with current coverage state, `invokes_tool` links, runs (correlated by run id only), decisions / executions /
  independently observed effects as separate objects, deploy relationships, the declared running artifact
  reference, and scoped controls with their test state. Each object carries `record {type,id,ref,body}` copied from
  the record, `provenance`, a `basis` (declared/configured/observed/tested/unknown/hypothetical), a status as text +
  glyph (never colour only) and `draw {line, transit}` where `transit` is true only for observed records.
  Missing registries are reported in `unavailable` ("unknown, not absent"); a self-reported "effect" is dropped.
- Server: `GET /api/projects/:p/assets/:asset/interior` (viewer, read-only) builds it from the store's graph,
  events, sources, coverage, the controls registry and `grantElements(latestSnapshot)` (`exploration.ts`, now exported).
- MCP: `dk_asset_interior { asset_id }` (read-only) returns exactly the API record.

## Limitations
- The browser has no controls registry or authorization snapshot in its loaded data, so it lists those as
  "unknown, not absent"; the API/MCP interior includes them when the server holds them.
- Interior rows select the underlying record kinds (event / relationship / source); there is no separate
  `interior:` selection kind in the URL. Route, artifact and control records are shown inline (copied body +
  provenance) rather than as their own selection.
- Software WebGL only; no GPU claim.
