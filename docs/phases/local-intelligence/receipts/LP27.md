## What LP27 adds (commit 0dc7e74)

- `eval/local/variants.ts` (`li-variants-1`): 24 variant families over the reviewed LP07 documents LW-01 (saas), LW-02
  (agent workspace), LW-03 (delivery identity). Categories: observer faults (V01, V02, V17), delayed evidence (V03, V16),
  dropped evidence (V04), out-of-order receipt (V05, V23), duplicate stimulus (V06, V15, V22), budgeted noise (V07, V18;
  `NOISE_BUDGET` 24, typed `NoiseBudgetExhausted` beyond it), injected instructions in free-text fields (V13, V14, V20),
  removed denials (V08, V19, V21), lease-escape attempts (V09 observer resource, V10 undeclared admin route, V11 URL in a
  resource id + `command` field, V12 path traversal) and a partial run (V24). Each family names the existing regression
  file it extends (unchanged), declares exactly what it changes (`removed` clean steps, `inserted` actions, `fields`), and
  declares how the LP25 private key may change (`identical`, `superset`, `changed_steps`, `refused`).
- `describeChanges`/`unintendedChanges`: LCS alignment of the step lists, then field-level pairing inside each gap.
- `safetyScan`: static guard against URL/scanner/shell/malware/credential-harvest text.
- `eval/test/li-lp27-variants.test.ts` (10 tests): runs each executable variant in a fresh local laboratory (LP05/06
  supervisor, LP07 runner) and grades it with the LP25 referee (`answerKey`, `gradeAnswer`, `logicalKey`).

## Limitations

- The injected-instruction pairs are graded with the deterministic scripted investigator, which ignores free text by
  construction; this establishes the clean/injected protocol and that the world/key are unchanged, not that a model
  resists injection. Real-model injection resistance: **not_exercised** (no model run in this session).
- Whether each injected text reaches an investigator-visible record depends on the service (message/artifact content);
  the test does not assert visibility.
- Variants are scripted transformations of the three reviewed scenarios, not seeded held-out generation; the LP25
  held-out generator already toggles several of the same faults.
- External gates in DEFERRALS.json stay deferred.
