## What changed

- `apps/server/src/exploration.ts`:
  - `dk.analysis_state.v1` — canonical view of grants (every statement of every layer: identity, boundary, trust,
    resource, SCP; an unknown layer is an explicit element), declared routes, agent tool links, deployed artifacts and
    telemetry sources. Element identity is `(kind, authority, id)`: a grant's authority is its AWS account and its id
    is the name within that account (`user/deployer#identity#pol#Read`); an artifact's authority is its registry
    (`parseArtifact`); routes/tools use the asset's provider scope or `project/environment`. State hash =
    sha256(canonical state).
  - Candidates: a finite list of typed changes (`add | remove | modify` × `grant | route | tool | artifact | source`)
    with per-kind attribute allowlists (statements limited to IAM statement keys; no executable/target fields) applied
    to a clone in namespace `branch:<proposal digest>`; addressing an element under the wrong authority is refused
    (409) rather than resolved by name.
  - Comparison (`mode: model_only`): added / removed / modified keys, access probes evaluated on the baseline and the
    rebuilt candidate snapshot (`basis: configured_permission`, `observed_use: false`), the R04.4 review of the
    candidate, condition keys, unassessed paths (unresolved or conditional probes, unsupported provider/action
    semantics, changed grants no probe exercises, and every non-grant change as "declared change only; runtime
    behaviour not executed").
  - Receipt `dk.analysis_receipt.v1`: base and candidate state hashes, proposal digest, the exact state (graph
    revision, snapshot id + digest, source config revisions), policy version, condition keys, unassessed paths,
    change keys, probe results, and `receipt_digest` = sha256(canonical receipt). No timestamp is inside the digest,
    so equal inputs give equal digests. `recheck` re-derives the candidate hash and reports `reproducible: false`
    once the baseline has moved.
  - `dk.path_explanation.v1` — "why can this reach that?": bounded simple paths (≤ 6 hops, ≤ 20 paths) over the
    baseline or a candidate graph with per-hop provenance (`evidence_refs`), basis (`observed_activity` only when the
    relationship's own evidence level is `observed` and it has evidence refs; otherwise declared / inferred /
    proposed), and a presentation hint (`animate` true only for observed activity); an optional permission path via
    `accessPaths` whose hops are always `configured_permission`, never observed, never animated (`dashed_conditional`
    for conditional), with unresolved prerequisites named (unsupported constructs, missing inputs, conditions not
    evaluated, provider/action semantics outside S3 + `sts:AssumeRole`).
  - Storage: `analysis_comparisons` (migration `ANALYSIS_MIGRATION`, append-only triggers). Routes:
    `GET /api/projects/:p/analysis/state` (viewer), `POST …/analysis/comparisons` (analyst, `base_state_hash`
    required: 428 missing / 409 stale), `GET …/analysis/comparisons/:id`, `GET …/comparisons/:id/recheck`,
    `GET …/analysis/paths` (viewer). `hardening.test.ts` rewind drops the new table.
- Console: Coverage → **Paths** tab (`workspaces/coverage/PathInspector.tsx`): from/to assets, optional
  principal/action/resource, lists of hops with line pattern, provenance and conditions; `lib/pathInspector.ts`
  `hopStyle` re-enforces client-side that only observed activity with evidence refs animates.

## Limits

- Model-only. Executed-local comparison (instantiating the candidate in a disposable run) is LP16+; external
  effectiveness is deferred (EXT01).
- Permission semantics are exactly the LP01 evaluator's (AWS S3 actions and `sts:AssumeRole`, conditions not
  evaluated); everything else is unresolved by design.
- Graph paths are declared reachability through relationship edges, not packet-level network reachability.
- Artifact authority is parsed from the declared deployment reference; an unqualified reference gets authority
  `unqualified` (it is still distinct from any registry-qualified artifact).
- The 3D ghosted baseline/branch comparison (05 §7) is LP17+; this package provides lists and receipts.
- No model call; AI execution not exercised.
